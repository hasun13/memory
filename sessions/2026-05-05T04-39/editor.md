# 🎥 솔깃야담 영상 구성 가이드: 비밀 기록 - 조선 왕실의 그림자 코드
**(장르: 미스터리 다큐멘터리 | 목표 분량: 90분)**

본 가이드는 Writer가 작성한 스크립트와 Designer가 구축한 비주얼 라이브러리를 결합하여, 시청자의 몰입도를 극대화하고 '지적 충격'과 '회상'의 감정선을 유지하는 데 초점을 맞춘 최종 제작 디렉션입니다.

---

## 🎬 I. 전체 페이싱 (Pacing & Tone) 전략

| 요소 | 설명 | 목표 효과 |
| :--- | :--- | :--- |
| **전체 톤** | 학술적 진지함 (Academic Seriousness) + 영화적 미스터리 (Cinematic Mystery). 다큐멘터리이지만, 마치 스릴러의 전개처럼 긴장감을 유지해야 함. | 시청자가 단순한 '역사 학습'이 아닌 '진실을 추적하는 경험'에 집중하게 만듭니다. |
| **속도 변화** | **Slow Build-up (0~15분)** $\rightarrow$ **Moderate Investigation (15~60분)** $\rightarrow$ **Dramatic Climax/Suspense (60~90분)** 순으로 점진적인 속도 변화를 줍니다. | 지루함을 방지하고, 주요 발견 지점마다 카타르시스를 제공합니다. |
| **사운드 디자인** | 배경음악은 일관되게 낮고 웅장하며 (Ambient Orchestral), 나레이션에 따라 긴장감을 높이는 사운드 스팅(Sting)이나 정적을 반드시 활용해야 합니다. | 시각적인 공백과 청각적인 밀도를 조절하여 몰입도를 유지하는 것이 핵심입니다. |

---

## ⏱️ II. 시간대별 상세 구성 디렉션 (Time Code & Action Guide)

### A. 도입부: The Hook (00:00 ~ 05:00)
**[목표]**: 시청자의 모든 이성적 방어벽을 무너뜨리고, '이건 내가 알던 역사가 아니다'라는 의문을 강하게 심는다.
**[페이싱]**: 극도로 느림 (Slow & Deliberate). 첫 3분은 말보다 침묵과 비주얼에 집중해야 합니다.

| Time Code | 내용/스크립트 포인트 | Visual Action / B-roll 지시 | 자막/그래픽 액션 |
| :--- | :--- | :--- | :--- |
| **0:00 - 1:30** | (침묵과 배경음악만 흐름) "여러분은 역사를 배울 때 어떤 이야기를 들으셨나요?" | **P1 클로즈업 (필수):** 오래된 문서 조각을 극단적으로 슬로우 모션으로 보여줌. 먼지 입자가 빛에 반사되는 모습(Micro-detail) 강조. 카메라 움직임은 매우 느린 틸트(Tilt). | 자막: "공식 기록의 이면에서..." (간헐적 등장, 속삭이는 느낌) |
| **1:30 - 3:00** | "만약 제가 말씀드린다면요... 여러분이 지금까지 알고 계신 조선의 역사는, 사실 엄청나게 거대한 '편집본'일지도 모른다고 말입니다." | **P2 (안개):** 안개가 자욱한 궁궐 전경을 배경으로 하되, 화면 전체에 짙은 명암 대비(Contrast)를 유지. 특정 지점만 희미하게 빛나도록 연출. | 그래픽: '편집본'이라는 단어 주변에 깨지거나 휘어지는 필터 효과 적용 (시각적 충격). |
| **3:00 - 5:00** | "조선 역사에 등장하는 모든 비밀은, 왕이 아닌 그림자 속의 누군가가 설계했습니다..." **(후킹 대사)** | **P3 (실루엣) + P4 전환:** 실루엣을 보여주다가, 갑자기 화면이 어두워지며 복잡한 기호들이 빠르게 플래시처럼 지나감. 이 기호들을 해독하는 학자들의 손 클로즈업(P4)으로 급격하게 전환하며 다음 섹션 예고. | 자막: "코드 (CODE)"를 반복적으로, 마치 암호를 해독하듯 보여줌. |

### B. 본론 1: 미스터리 시대 배경 설정 - 세도정치와 기록의 파괴 (05:00 ~ 30:00)
**[목표]**: 지식 전달을 통해 신뢰도를 구축하는 구간. 설명이 길어지므로, 시각적 변화를 주어 리듬감을 유지해야 합니다.
**[페이싱]**: 조사 및 분석 단계 (Investigative Pacing). 정보는 전문적으로, 비주얼은 미스터리하게 풀어냅니다.

| Time Code | 내용/스크립트 포인트 | Visual Action / B-roll 지시 | 자막/그래픽 액션 |
| :--- | :--- | :--- | :--- |
| **5:00 - 12:00** | (세도정치 배경 설명 시작) "권력의 중심에는 늘 비밀이 존재했습니다." | **P2 (궁궐 전경) 활용:** 당시 세도 가문과 관련된 건물이나 지형을 보여주되, 평범한 모습으로 지나가며 '겉모습'에 초점을 맞춘다. B-roll로 웅장함 대비 폐쇄성을 강조. | 인포그래픽: 시간의 흐름(Timeline)을 활용하여 세도정치의 맥락적 배경을 깔끔하게 정리해 제시. |
| **12:00 - 25:00** | (실제 사건 및 기록 파괴 과정 설명) "이러한 상황에서, 특정 인물들은 공식 역사에서 지워졌습니다." | **P4 집중 사용:** 학자들이 모여 자료를 분석하는 장면을 반복적으로 보여준다. 손에 초점을 맞추어 '증거'가 발견되는 순간마다 클로즈업으로 전환 (예: 바랜 잉크 자국, 특정 기호의 우연한 일치 등). | 그래픽: 사건 관련 인물의 이름/직위를 언급할 때, 마치 신문의 헤드라인처럼 굵고 충격적인 타이포그래피를 사용. |
| **25:00 - 30:00** | (본론 마무리 및 다음 주제 예고) "하지만 그들이 남긴 '코드'가 있습니다." | **P1/P4 결합:** 화면 전체에 퍼즐 조각이 맞춰지듯 다양한 문서 파편(P1)이 모이고, 그 위에 미스터리한 기호들(P4)이 떠오르는 연출을 합니다. BGM의 볼륨을 최고조로 끌어올렸다가 갑자기 뚝 끊기며 다음 섹션으로 전환합니다. | 자막: "다음 기록은... [주제 2] 입니다." (강렬한 임팩트). |
